# Video Studio Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a durable Video Studio project catalog and a responsive Research → Script → Production workflow surface without exposing nonfunctional render controls.

**Architecture:** Video Studio projects live on the selected execution host behind typed runtime RPC methods. A host catalog validates every record and publishes atomic snapshots; the renderer owns only selection and form drafts. The page is a top-level App Rail destination and remains independent of future HyperFrames and Remotion job entities.

**Tech Stack:** TypeScript, React 19, Zustand, Zod, Orca runtime RPC, atomic snapshot persistence, Vitest, fixture screenshots, Electron CDP.

**Spec:** `docs/superpowers/specs/2026-11-23-general-chat-video-studio-design.md`

## Global Constraints

- Store host data on the owning host and never construct remote paths in the renderer.
- Project IDs are generated by the host and never inferred from titles.
- Accept only aspect ratios `16:9`, `9:16`, and `1:1`; duration is an integer from 5 through 3600 seconds.
- Preserve the last durable catalog when a mutation fails.
- Do not add HyperFrames, Remotion, Deep Research, or fake render actions in this milestone.
- Follow `docs/STYLEGUIDE.md` and existing shadcn primitives.
- Run `pnpm check:changed` once after all implementation edits.


Expected: FAIL because `VideoStudioCatalog` does not exist.

- [ ] **Step 3: Implement the catalog**

Store `video-studio-projects.json` below the runtime's canonical user-data directory. Use Orca's atomic publication utility and a single mutation lane. A mutation computes the next snapshot, writes it, then replaces memory:

```ts
const next = applyMutation(current, mutation)
await writeSnapshot(next)
current = next
return structuredClone(next)
```

Never assign `current = next` before the durable write succeeds.
